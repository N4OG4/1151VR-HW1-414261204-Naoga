# 製作流程和相關操作
首先，下載 unity hub
在此同時，於 github 開啟新 repo 設定為"公開" .gitignore 套用 unity
當安裝好 unity hub 後，開啟專案
上網尋找 3D 模型，例如 [Utah teapot](https://graphics.cs.utah.edu/teapot/)
下載下來導入專案 Assets 目錄，再視窗中拖曳至 Scene
接著移動模型至主相機正前方，點擊視窗上方的 ▶ 執行專案
確認畫面中有顯示模型後，開啟螢幕錄影再執行一次
最後將影片上傳至 YouTube
